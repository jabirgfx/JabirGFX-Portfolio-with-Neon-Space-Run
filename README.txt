JabirGFX Portfolio Website
============================

This is a static, hosting-ready website.

Upload the CONTENTS of this folder to your domain's public_html (or equivalent).
No Node.js, PHP, database, build step, or framework is required.

Files:
- index.html
- style.css
- script.js
- assets/

The design is responsive for desktop/tablet/mobile.

Before publishing:
1. Replace the cropped reference images in assets/ with your original logo/portrait/project images for best quality.
2. Replace # social links in index.html with your real profile URLs.
3. Add your CV as assets/JabirGFX-CV.pdf and update the Download CV button.
4. Change project/service text if needed.
